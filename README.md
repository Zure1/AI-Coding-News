# AI Coding News

Weekly briefings on AI coding tools, coding agents, and agentic development workflows.

## Scope

The briefings focus on practical updates that affect building, reviewing, testing, shipping, or maintaining software with AI coding tools.

Included topics:

- coding agents and IDE agents
- AI coding assistants
- autonomous repo workflows
- CI and PR automation
- code review and test-generation agents
- relevant benchmarks, reliability findings, and security risks
- notable open-source AI coding projects

General AI news is excluded unless it directly affects software development workflows.
