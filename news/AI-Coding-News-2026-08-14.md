# AI Coding News — 2026-08-14

**Date range:** 2026-08-08 → 2026-08-14

## Key updates

This week was mostly about **model choice, portable agent extensions, multi-agent orchestration, local models, and tighter agent security**.

| Update | What changed | Source link |
|---|---|---|
| **Gemini 3.7 Flash reached GitHub Copilot** | Google’s latest Flash model is rolling out across VS Code, Visual Studio, Copilot CLI, Copilot cloud agent, the Copilot app, JetBrains, Xcode, and Eclipse. GitHub says its early testing shows gains over the previous version in web/app development, agentic coding, code quality, codebase research, final-output quality, and verification on complex coding tasks. It is positioned as a fast model for coding and agent workflows rather than a general-purpose flagship. | [GitHub Changelog](https://github.blog/changelog/2026-08-13-gemini-3-7-flash-is-now-available-in-github-copilot) |
| **Agent Plugins 1.0 became a portable extension format across major coding-agent clients** | VS Code, Copilot CLI, the Copilot SDK, and the Copilot app now support Agent Plugins 1.0. A single package can carry reusable agent skills plus tool/server configuration instead of maintaining separate manifests for each client. Enterprise controls can install, block, or restrict plugins and marketplaces through managed settings. | [GitHub Changelog](https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app) |
| **Claude Code expanded multi-agent workflows and hardened its execution boundary** | Claude Code v2.1.232 turns subagent forking on by default, lets sessions message other live sessions by name, and runs high-effort code review in a background agent. The same release fixes PowerShell and Git Bash permission-bypass paths, requires separate trust for nested repositories, hardens the Linux filesystem sandbox and cross-session socket handling, and adds more GitLab-token redaction. Earlier in the week, v2.1.229 also fixed the generated GitHub code-review workflow so reviews are actually posted and stopped auto-approving dangerous `git`/`gh` flags such as `--force`, `--amend`, and `--no-verify`. | [Claude Code v2.1.232](https://github.com/anthropics/claude-code/releases/tag/v2.1.232) · [Claude Code v2.1.229](https://github.com/anthropics/claude-code/releases/tag/v2.1.229) |
| **GitHub Copilot for JetBrains added persistent memory and Ollama** | Copilot can now retain useful project context across agent-chat sessions in JetBrains IDEs. Ollama is available as a BYOK provider, giving developers a path to use locally served models inside the Copilot experience. The update also expands Codex workflows with instructions and skills, adds more enterprise controls, and improves reliability around terminals, cloud agents, customizations, and tool execution. | [GitHub Changelog](https://github.blog/changelog/2026-08-11-copilot-memory-and-ollama-in-github-copilot-for-jetbrains) |
| **Microsoft shipped MAI-Code-1.1-Flash as a lower-cost coding model in Copilot** | MAI-Code-1.1-Flash is Microsoft’s updated small-tier coding model. It adds native vision and improves coding quality, instruction following, tool use, and performance over MAI-Code-1-Flash. GitHub says its list price is 73% lower than the previous model; annual Copilot subscribers are charged a 0.25× premium-request multiplier. It is available across Copilot CLI, cloud agent, app, web chat, VS Code, Visual Studio, JetBrains, Eclipse, Xcode, and GitHub Mobile. | [GitHub Changelog](https://github.blog/changelog/2026-08-11-mai-code-1-1-flash-available-in-github-copilot) |
| **Copilot usage reports now expose token consumption per model** | GitHub’s AI usage report now breaks each model’s consumption into input, output, cache-read, and cache-write tokens alongside the resulting AI credits. This makes model-level cost analysis possible without reconstructing charges from aggregate credit totals. The breakdown is available to Copilot Business and Enterprise admins and individual Copilot users. | [GitHub Changelog](https://github.blog/changelog/2026-08-11-per-model-token-breakdown-in-the-usage-report) |
